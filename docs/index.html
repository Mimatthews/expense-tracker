Know where the money went.

Ledger is a full-stack expense tracker: add transactions in seconds, sort them into colour-coded categories, and read the month at a glance through live charts. Built with React, FastAPI and SQLite — small enough to read in an afternoon, complete enough to actually use.

What it does

Everything you expect, nothing you don't.

The three things an expense tracker must nail: fast entry, honest categorisation, and a summary you can read in five seconds.

Transaction CRUD

Add, edit and delete expenses or income. Amounts are stored as integer cents, so totals never drift the way floats do.

Categories you own

Colour-coded buckets with full CRUD. Deleting a category keeps its transactions and marks them uncategorised — no silent data loss.

Monthly summaries

Spend, income, net cash flow and savings rate per month, with month-over-month deltas and a six-month trend line.

Four live charts

Cash-flow area chart, interactive category donut, daily spending bars and a top-merchants ranking — all driven by real SQL aggregates.

Search, filter, export

Full-text search on description and merchant, category and type filters, sortable columns, pagination and one-click CSV export.

Yours alone

One SQLite file on your machine. Multiple currencies for display, dark UI, keyboard-friendly forms, and a responsive layout down to 380px.

Under the hood

Boring parts chosen on purpose.

Two small services, one database file, no build magic. The database is the source of truth and the charts are aggregates computed in SQL, not in the browser.

Get started

Running in about a minute.

Two terminals, no Docker, no accounts. Python 3.10+ and Node 18+ is all you need.

1 · Backend

# terminal 1
cd backend
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m app.seed        # optional demo data
uvicorn app.main:app --reload

2 · Frontend

# terminal 2
cd frontend
npm install
npm run dev

Open http://localhost:5173. Interactive API docs live at http://localhost:8000/docs. Run the test suite with pytest in backend/.
